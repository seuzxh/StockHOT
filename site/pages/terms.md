# 使用规则

版本：0.1
生效日期：2026-10-17
运营主体：个人自建实例
联系方式：通过站内反馈页联系

StockHOT 是资讯索引。
内容不构成投资建议。

## 1. 内容边界

本站汇总公开资讯和授权数据。
本站保留原文链接和时间。
标题、摘要和关联结果可能有误。
重要信息必须以原始披露为准。

本站不提供交易信号、买卖建议、目标价或收益预测。

## 2. 版权与引用

原文版权归各来源所有。
本站默认只展示摘要和原文链接。
只有来源明确允许时，本站才展示全文。

## 3. 更正与下架

来源方可通过反馈页提出更正或下架请求。
本站保留更正和撤回记录。

## 4. 接口使用

RSS、公开 API 和 MCP 为匿名只读接口。
调用方必须遵守缓存与限流响应头。
调用方遇到 429 时必须遵守 Retry-After。

## 5. 免责声明

本站按现状提供。
本站不保证内容完整、准确或持续可用。
