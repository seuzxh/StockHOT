## 实时能力验证

### iFinD MCP

三个工具都已直接调用。
`search_news` 返回 HTTP 200。
`search_notice` 返回 HTTP 200。
`search_trending_news` 返回 HTTP 200。

账户当前请求额度已耗尽。
服务只返回额度提示。
本次无法核对资讯元数据。
系统不得把提示当作资讯。

### 网页来源

韭研公社完成周末匿名技术预览。
预览得到 26 条唯一链接。
五个交易日验证尚未完成。

萝卜投研只返回 SPA 外壳。
robots 禁止资讯相关路径。
系统没有访问这些路径。

详见 `docs/source-validation.md`。
