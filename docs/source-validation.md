# 实时来源验证记录

## 结论

韭研公社已有最小网页列表配置。
该配置仍保持停用。

萝卜投研未配置采集适配器。
其资讯路径受 robots 限制。

同花顺只使用 iFinD MCP。
系统没有同花顺网页采集配置。

## 验证规则

来源启用前须通过五个交易日。
每天记录标题、链接和时间。
每天核对分页与重复结果。
任一天失败都会中断验收。

验证不得绕过登录或付费墙。
验证不得绕过 robots 规则。
验证只访问公开匿名页面。
