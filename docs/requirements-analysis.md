# StockHOT 需求分析

版本：0.2。日期：2026-10-17。
状态：评审稿。StockHOT 为暂用名。
目标读者：产品负责人、开发者、验收者。

## 1. 结论

首版定位为个人股票资讯工作台。
覆盖盘前梳理、盘中跟踪、盘后复盘。
系统必须保留原文与证据链。

AIHOT 可作为采集与展示底座。
股票关联和证据分类需要补充。
数据接入必须先于效果承诺。

## 3. 用户问题与成功标准

| 场景 | 当前问题 | 用户需要的结果 |
|---|---|---|
| 盘前梳理 | 隔夜资讯分散，重复报道多 | 快速掌握新增事件及证据 |
| 盘中跟踪 | 资讯滚动快，重要变化易遗漏 | 看到关注股票的新进展 |
| 盘后复盘 | 信息顺序混乱，旧闻混入 | 按时间回看事件演变 |
| 判断线索 | 观点常被写成确定事实 | 识别出处、推测与冲突 |

核心价值是减少阅读与核验成本。
热度只代表资讯关注程度。
系统不把热度解释为上涨概率。
首版不生成买卖指令。

## 4. 一手消息的定义

“一手”按具体内容判断。
网站名称不能直接证明一手性。
发布速度也不能证明一手性。

| 内容类型 | 判定依据 | 展示方式 |
|---|---|---|
| 原始披露 | 公司、机构直接发布的原文 | 原始披露标记及原文入口 |
| 原创报道 | 媒体直接采访或调查 | 原创报道标记 |
| 转载报道 | 引用其他机构或媒体 | 转载标记及上游出处 |
| 观点与线索 | 社区判断、纪要转载、传闻 | 待核验标记 |
| 无法判定 | 证据不足或出处缺失 | 来源类型待核验 |

原始披露只证明发布主体与原文。
它不保证预测结果一定兑现。
系统保留“拟”“预计”等限定词。
系统不能把纪要转载改为官方披露。

需要追溯时，优先寻找原始链接。
候选包括巨潮资讯及交易所公告。
也可使用公司与政策发布机构原文。
新增自动采集源须单独确认。

## 5. 来源接入分析

本次检查日期为 2026-10-17。
页面可读不等于自动采集可用。
登录权益也不等于自动处理授权。

| 来源 | 本次证据 | 产品用途 | 接入验证重点 |
|---|---|---|---|
| 韭研公社 | 首页可读，含研究与纪要转载 | 题材发现、社区线索 | 列表、详情、时间、转载出处 |
| 同花顺 | iFinD 技能列出新闻、公告和热点检索 | 通过 iFinD MCP/skill 获取资讯 | 工具权益、检索覆盖、字段与配额 |
| 原始披露候选 | 巨潮资讯首页可读 | 核验与原始公告入口 | 公告标识、附件、许可范围 |

同花顺资讯仅通过 iFinD MCP/skill 获取。
不使用同花顺网页爬取。
原文链接仅用于追溯和用户跳转。
接口失败时不得回退网页爬取。
当前未验证两个来源的稳定自动接入。
已验证 iFinD 三项资讯工具可调用。
长期覆盖和配额仍需连续验收。

每个来源都需完成以下验证：

1. 确定栏目或检索主题与内容范围。
2. 确认允许的访问及处理方式。
3. 测试标题、时间、原文与正文。
4. 检查结果上限、增量与重复记录。
5. 测试凭据失效、配额与访问限制。
6. 连续观察后决定是否启用。

同花顺固定使用 iFinD MCP/skill。
其余来源优先使用允许的订阅或接口。
其余来源可验证允许采集的公开页面。
动态页面可评估独立适配器。
不把浏览器可见当成适配成功。
人工导入属于降级能力。
人工导入不计入自动接入验收。

### iFinD 接入约束

技能封装了 iFinD MCP 的新闻公告服务。
新闻使用 search_news。
公告使用 search_notice。
热点使用 search_trending_news。
以上能力来自技能参考文档。
2026-10-18 已完成实际调用验证。

语义检索可能只返回相关段落。
系统不得把片段表述为全文。
检索无结果不代表市场没有资讯。
检索结果也不代表同花顺全量内容。
查询主题、时间窗和结果上限须留档。
实际字段、分页与历史范围需实测。

建议用后端适配器调用该服务。
结果通过 AIHOT 的 external 入口入库。
适配器负责检索排程、去重和配额。
它不依赖当前聊天持续运行。
网页浏览不能触发 MCP 取数。
具体入库映射须在实施阶段验证。

## 6. 方案比较

| 方案 | 主要能力 | 优点 | 限制 |
|---|---|---|---|
| A 配置型资讯站 | 替换来源、分类、提示词 | 改动少，可快速验证 | 股票关联与证据链不足 |
| B 股票资讯工作台 | A 加股票关联、核验与关注 | 对齐三个使用场景 | 需要少量行业模块 |
| C 全量投研平台 | 行情、研报库、问答与策略 | 能覆盖更广研究流程 | 授权与建设范围显著扩大 |

推荐方案 B。
先证明采集、摘要与追溯可用。
再扩展股票关联和个人关注。
方案 C 不属于当前首版。

## 8. 首版不包含

- 自动交易、荐股排名、收益预测。
- 分钟行情、盘口、资金流计算。
- 全网覆盖及完整研报数据库。
- 付费墙绕过与登录限制绕过。
- 团队协作、收费会员和公开社区。
- 未获允许的全文镜像与附件分发。

## 10. 试运行指标

以下数字是建议验收目标。
它们不是当前已达到的表现。

| 指标 | 建议目标 | 测量方法 |
|---|---|---|
| 来源验证 | 每源连续 5 个交易日 | 保存采集记录及失败原因 |
| 网页列表覆盖 | 网页来源样本覆盖率至少 95% | 已采条目除以可采条目 |
| iFinD 入库完整率 | 合格返回条目至少 95% 入库 | 入库数除以同批合格去重返回数 |
| 原文完整性 | 已展示条目 100% 有原文入口 | 核对展示清单 |
| 摘要追溯 | 事实句 100% 有来源对应 | 人工逐句检查 |
| 严重失真 | 抽检中为 0 | 检查主体、数值、否定与日期 |
| 股票映射准确率 | 已确认映射至少 98% | 正确映射除以已确认映射 |
| 模糊实体处理 | 不确定映射 100% 明示 | 检查待确认样本 |
| 聚合误合并率 | 不高于 2% | 误合并组除以已审查组 |
| 重点命中率 | 至少 80% | 用户认可条目除以推荐条目 |
| 重点召回率 | 至少 80% | 命中重点除以人工重点 |
| 盘中发布延迟 | P95 不超过 15 分钟 | 可采时间到站内可见时间 |
| 系统处理延迟 | P95 不超过 5 分钟 | 首次采到到站内可见时间 |

时效目标以允许的访问频率为前提。
盘中目标还依赖采集调度扩展。
上游默认节奏不能证明该目标达标。
无法观测可采时间时，明确标注。
此时不得宣称端到端时效达标。
故障与受限窗口必须单列披露。
覆盖率不声称覆盖目标网站全站。
iFinD 合格条目须有时间及可追溯出处。
缺字段与被截断条目须单列计数。
iFinD 入库完整率不代表检索召回率。
检索召回另用固定人工重点样本评估。
固定查询主题、时间窗和结果上限。
检索上限与无结果批次须保留记录。

建议准备至少 200 条人工标注资讯。
样本覆盖两个来源及正反两类重点。
另备至少 50 组事件边界样本。
先分校准集与验收集，再调规则。
首版指标仅用于资讯质量验收。
